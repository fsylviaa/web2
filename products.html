在线工具 Browser tool · 02

Markdown 知识卡片
Markdown Card Studio

把 Markdown 即时排版成适合分享的知识卡片和 PNG 长图。所有内容只在浏览器里处理，输入经过 DOMPurify 清理后才进入预览。

  • 支持标题、列表、引用、代码块和 GFM 表格
  • 简约、杂志、便签三种主题，可调字号、行距、背景色和内容宽度
  • 自动保存草稿，支持 Markdown 导入下载与 PNG 长图导出

海报工厂
Poster Factory

在浏览器里打开就能用的生成式海报工作室。选好尺寸，挑几个颜色，拖动参数或者点一下骰子随机，就能得到一张独一无二的海报或壁纸，一键导出 PNG。

  • 7 种常用尺寸预设：海报、手机壁纸、小红书、Instagram、电脑壁纸、A4
  • 朱红、墨黑、墨绿、蜂蜜黄、米白组成的东方调色盘
  • 随机生成、撤销 / 重做，全中文界面

周末实验 Weekend experiment · 01

雾镜自拍
Fog Mirror

把想说的话，写在雾里。打开前置镜头，镜面会慢慢起雾，用食指在空中划过就能擦开水雾、写字画画，再比个剪刀手拍下这一刻。

  • ☝ 食指移动擦开水雾，🤏 捏合切换粗细笔，🖐 张开手掌重新起雾，✌ 剪刀手触发 3 秒自拍倒计时
  • 用 MediaPipe 实时识别手势，不开摄像头也能用鼠标或手指体验
  • 全部在浏览器里完成：画面不上传、不存储，照片只在本机生成
